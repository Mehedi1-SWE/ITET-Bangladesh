# ITET Bangladesh

Full-stack website implementation for **The Institution of Textile Engineers & Technologists (ITET), Bangladesh**.

## Tech Stack

- Next.js 16
- React 19
- JavaScript
- Tailwind CSS 4
- MongoDB (backend phase)
- Next.js Route Handlers (backend/API phase)

## Getting Started

```bash
git clone https://github.com/Mehedi1-SWE/ITET-Bangladesh.git
cd ITET-Bangladesh
npm install
npm run dev
```

Then open `http://localhost:3000`.
